A tool for automating radio frequency (RF) spectrum monitoring. Instead of engineers straining their eyes to watch waterfall charts in SDR# or GQRX, this script captures raw data from the HackRF, passes it through a digital signal processing (DSP) pipeline, and uses Machine Learning to automatically flag anomalous frequency bands or signals.
Data Flow Ingestion: Pulls raw IQ data directly from the HackRF. DSP: Uses numpy and scipy to perform FFT, noise filtering, and signal gain calculation. Anomaly Detection: Feeds processed data arrays into a Hidden Markov Model (hmmlearn) and scikit-learn classification algorithms to detect unusual patterns. Models are saved/loaded using joblib. Web UI: Uses Flask to set up a local server. Spectrograms are generated using matplotlib. Command to run: Installation (using venv is recommended): python -m venv venv source venv/bin/activate pip install numpy scipy scikit-learn joblib flask hmmlearn matplotlib Run (Dev / Debug UI Mode) If you only want to test the UI or modify the Flask code without connecting the hardware board: python SDR-BLUE-TEAM.py --web-only
